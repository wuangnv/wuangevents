Problem Statement
Đặt Vấn Đề
Thực tế quản lý sự kiện tại Việt Nam hiện nay đặt ra nhiều thách thức.
🎟️
Bán vé phân tán
Vé bán qua nhiều kênh khác nhau — mạng xã hội, Zalo, thủ công — gây khó kiểm soát, dễ vé giả, không theo dõi được thống kê.
🦑
Không có sơ đồ ghế
Ban tổ chức thiếu công cụ quản lý sơ đồ chỗ ngồi theo khu vực và hàng ghế — dẫn đến xung đột chỗ, trải nghiệm kém.
📲
Check-in thủ công
Nhân viên kiểm tra vé thủ công, chậm, dễ sai sót, không thể xác thực vé điện tử QR code nhanh chóng tại cổng sự kiện.
💡
Giải pháp: WuangEvents
Xây dựng nền tảng web tích hợp đầy đủ: quản lý sự kiện, bán vé online, sơ đồ chỗ ngồi Canvas, thanh toán VNPAY/MoMo/ZaloPay, check-in QR camera thời gian thực — cho 4 vai trò sử dụng độc lập.

Technical Highlights
Tính Năng Kỹ Thuật Nổi Bật
🎨
Canvas Seat Map Interactive
HTML5 Canvas API tự vẽ sơ đồ ghế theo dữ liệu DB. Màu sắc khu vực, trạng thái ghế real-time. Click-to-select với highlight animation. Responsive trên mọi thiết bị.
📷
WebRTC QR Check-in Camera
getUserMedia() stream → canvas decode → jsQR → AJAX verify. Không cần app mobile riêng. Chạy trực tiếp trên trình duyệt — nhanh, chính xác, bảo mật.
⏱️
15-Minute Seat Hold System
Khi chọn ghế, trạng thái chuyển sang "held" với timestamp. SQL Server Trigger + scheduled cleanup giải phóng ghế hết hạn. Concurrent access safe.
💳
Triple Payment Gateway
VNPAY (redirect + IPN callback) · MoMo (HMAC-SHA256 signature) · ZaloPay (MAC verify). Mỗi gateway có service class riêng, hỗ trợ sandbox & production.
🔐
Cookie-based Auth + BCrypt
ASP.NET Core Cookie Authentication với Claims-based identity. BCrypt.Net hash password với cost factor 12. Custom middleware kiểm tra phân quyền theo role.
⚡
Dapper + Stored Procedures
Micro-ORM Dapper cho query nhanh, kiểm soát SQL chủ động. Toàn bộ CRUD qua Stored Procedures — bảo mật SQL injection, dễ optimize, tách logic DB.
